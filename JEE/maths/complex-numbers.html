Iota & Integral Powers of i

A complex number is a number of the form \(z = a + ib\), where \(a, b\) are real numbers and \(i = \sqrt{-1}\) is the imaginary unit (called iota). The need for complex numbers arose because equations like \(x^2 + 1 = 0\) have no real solution. Complex Numbers form one of the most scoring and conceptually rich chapters for JEE Main & Advanced.

1.1 Definition of Iota (i)

The imaginary unit \(i\) is defined as the square root of \(-1\):

\[i = \sqrt{-1}, \quad i^2 = -1\]

Consequently:

\[\sqrt{-a} = i\sqrt{a} \quad (a > 0)\]

For example, \(\sqrt{-4} = 2i\), \(\sqrt{-9} = 3i\), \(\sqrt{-3} = i\sqrt{3}\).

1.2 Integral Powers of i — Cyclic Nature

🔥 Most Repeated PYQ — Cyclic Powers of i

Powers of \(i\) repeat in a cycle of 4:

\[i^1 = i, \quad i^2 = -1, \quad i^3 = -i, \quad i^4 = 1\]

For any integer \(n\):

\[i^{4n} = 1, \quad i^{4n+1} = i, \quad i^{4n+2} = -1, \quad i^{4n+3} = -i\]

In general, to find \(i^n\), divide \(n\) by 4 and use the remainder \(r\): \(i^n = i^r\).

1.3 Negative Powers of i

Using \(i^{-n} = 1/i^n = \bar{i}^{\,n}/|i|^{2n}\) or simply \(i^{-1} = -i\) (since \(i \cdot (-i) = -i^2 = 1\)):

\[i^{-1} = -i, \quad i^{-2} = -1, \quad i^{-3} = i, \quad i^{-4} = 1\]

1.4 Sum of Powers of i

⭐ Important — Sum Property

Since the cycle is \(i, -1, -i, 1\) with sum \(0\):

\[i + i^2 + i^3 + i^4 = 0\]

More generally, the sum of any 4 consecutive integral powers of \(i\) is 0. So:

\[i^k + i^{k+1} + i^{k+2} + i^{k+3} = 0 \quad \text{(for any integer } k \text{)}\]

For sum \(i + i^2 + \dots + i^n\): if \(n\) is a multiple of 4, sum = 0; else use remainder.

1.5 Large Powers — Formula for \(i^n\)

For any integer \(n\) (positive, negative, or zero):

\[i^n = \cos\left(\frac{n\pi}{2}\right) + i\sin\left(\frac{n\pi}{2}\right) = e^{in\pi/2}\]

This is a special case of De Moivre's theorem (covered later).

📝 PYQ — JEE Main 2023 (Jan 30 Shift 1)

Question: The value of \(i^{57} + \dfrac{1}{i^{25}}\) is:

(a) \(0\)

(b) \(2i\)

(c) \(-2i\)

(d) \(i\)

Solution:

\(57 = 4 \times 14 + 1\), so \(i^{57} = i^{4(14)+1} = i\).

For \(\dfrac{1}{i^{25}}\): \(25 = 4 \times 6 + 1\), so \(i^{25} = i\). Thus \(\dfrac{1}{i^{25}} = \dfrac{1}{i} = -i\).

\[i^{57} + \frac{1}{i^{25}} = i + (-i) = 0\]
\[0\]

Answer: (a) \(0\)

Algebra of Complex Numbers

Complex numbers can be added, subtracted, multiplied, and divided (except by zero) following rules analogous to real numbers, with the convention \(i^2 = -1\). The set of complex numbers forms a field.

2.1 Equality of Complex Numbers

🔥 Most Repeated PYQ — Equality Condition

Two complex numbers \(z_1 = a + ib\) and \(z_2 = c + id\) are equal if and only if:

\[a = c \quad \text{and} \quad b = d\]

That is, real parts are equal AND imaginary parts are equal. Note: Two complex numbers cannot be compared using \(<\) or \(>\) (no natural ordering).

2.2 Addition and Subtraction

For \(z_1 = a + ib\) and \(z_2 = c + id\):

\[z_1 + z_2 = (a+c) + i(b+d)\]
\[z_1 - z_2 = (a-c) + i(b-d)\]

Properties: Commutative, Associative, Additive identity = \(0 = 0 + i0\), Additive inverse of \(z = a + ib\) is \(-z = -a - ib\).

2.3 Multiplication

🔥 Most Repeated PYQ — Multiplication Rule

For \(z_1 = a + ib\) and \(z_2 = c + id\):

\[z_1 \cdot z_2 = (ac - bd) + i(ad + bc)\]

Obtained by expanding \((a + ib)(c + id) = ac + iad + ibc + i^2 bd = (ac - bd) + i(ad + bc)\).

Multiplicative identity = \(1 = 1 + i0\). Multiplicative inverse of \(z = a + ib \neq 0\):

\[z^{-1} = \frac{\bar{z}}{|z|^2} = \frac{a - ib}{a^2 + b^2}\]

2.4 Division

For \(z_1 = a + ib\) and \(z_2 = c + id \neq 0\):

\[\frac{z_1}{z_2} = \frac{z_1 \bar{z}_2}{z_2 \bar{z}_2} = \frac{(a+ib)(c-id)}{c^2 + d^2} = \frac{(ac + bd) + i(bc - ad)}{c^2 + d^2}\]

Method: multiply numerator and denominator by the conjugate of the denominator.

2.5 Properties (Field Axioms)

💡 Closure & Properties

  • Closure: Sum, difference, product, quotient (≠0) of complex numbers is complex.
  • Commutative: \(z_1 + z_2 = z_2 + z_1\), \(z_1 z_2 = z_2 z_1\)
  • Associative: \((z_1 + z_2) + z_3 = z_1 + (z_2 + z_3)\), similarly for product.
  • Distributive: \(z_1(z_2 + z_3) = z_1 z_2 + z_1 z_3\)
  • Note: Complex numbers cannot be ordered (no \(<\) relation).

📝 PYQ — JEE Main 2024 (Jan 29 Shift 2)

Question: If \((1 + i)z = (1 - i)\), then \(z\) equals:

(a) \(i\)

(b) \(-i\)

(c) \(1\)

(d) \(-1\)

Solution:

\[z = \frac{1 - i}{1 + i} \cdot \frac{1 - i}{1 - i} = \frac{(1-i)^2}{1^2 + 1^2} = \frac{1 - 2i + i^2}{2} = \frac{1 - 2i - 1}{2} = \frac{-2i}{2} = -i\]
\[z = -i\]

Answer: (b) \(-i\)

Conjugate of Complex Number & Properties

The conjugate of a complex number is obtained by changing the sign of its imaginary part. Conjugates are crucial for division, modulus, and many identities.

3.1 Definition

🔥 Most Repeated PYQ — Conjugate Definition

For \(z = a + ib\), the conjugate (denoted \(\bar{z}\) or \(z^*\)) is:

\[\bar{z} = a - ib\]

Geometrically, \(\bar{z}\) is the reflection of \(z\) in the real axis (x-axis) of the Argand plane.

3.2 Properties of Conjugate

🔥 Most Repeated PYQ — Conjugate Properties

  • \(\overline{z_1 + z_2} = \bar{z}_1 + \bar{z}_2\)
  • \(\overline{z_1 - z_2} = \bar{z}_1 - \bar{z}_2\)
  • \(\overline{z_1 z_2} = \bar{z}_1 \bar{z}_2\)
  • \(\overline{\left(\dfrac{z_1}{z_2}\right)} = \dfrac{\bar{z}_1}{\bar{z}_2}\) (\(z_2 \neq 0\))
  • \(\overline{(\bar{z})} = z\) (involution)
  • \(z + \bar{z} = 2\,\text{Re}(z) = 2a\)
  • \(z - \bar{z} = 2i\,\text{Im}(z) = 2ib\)
  • \(z \bar{z} = |z|^2 = a^2 + b^2\)
  • \(\bar{z} = z\) iff \(z\) is purely real
  • \(\bar{z} = -z\) iff \(z\) is purely imaginary
  • \(\overline{z^n} = (\bar{z})^n\)
  • If \(z = z_1 z_2 \dots z_n\) then \(\bar{z} = \bar{z}_1 \bar{z}_2 \dots \bar{z}_n\).

3.3 Real and Imaginary Parts via Conjugate

Useful identities to extract real and imaginary parts:

\[\text{Re}(z) = \frac{z + \bar{z}}{2}, \qquad \text{Im}(z) = \frac{z - \bar{z}}{2i}\]

📝 PYQ — JEE Main 2022 (June 26 Shift 1)

Question: If \(z = \dfrac{1 + 2i}{1 - i}\), then \(|z|\) equals:

(a) \(\sqrt{5/2}\)

(b) \(\sqrt{5}\)

(c) \(\sqrt{2}\)

(d) \(\sqrt{10}\)

Solution:

Using \(|z_1/z_2| = |z_1|/|z_2|\):

\[|z| = \frac{|1 + 2i|}{|1 - i|} = \frac{\sqrt{1^2 + 2^2}}{\sqrt{1^2 + (-1)^2}} = \frac{\sqrt{5}}{\sqrt{2}} = \sqrt{\frac{5}{2}}\]
\[|z| = \sqrt{\frac{5}{2}}\]

Answer: (a) \(\sqrt{5/2}\)

Modulus & Its Properties

The modulus (or absolute value) of a complex number is its distance from the origin in the Argand plane. It is one of the most tested concepts in JEE.

4.1 Definition

🔥 Most Repeated PYQ — Modulus Formula

For \(z = a + ib\):

\[|z| = \sqrt{a^2 + b^2}\]

Geometrically, this is the distance from origin to the point \((a, b)\). Also, \(|z|^2 = z \bar{z}\).

4.2 Properties of Modulus

🔥 Most Repeated PYQ — Modulus Properties

  • \(|z| \geq 0\), and \(|z| = 0 \iff z = 0\)
  • \(|z| = |\bar{z}| = |-z| = |-\bar{z}|\)
  • \(|z_1 z_2| = |z_1| \cdot |z_2|\)
  • \(\left|\dfrac{z_1}{z_2}\right| = \dfrac{|z_1|}{|z_2|}\) (\(z_2 \neq 0\))
  • \(|z^n| = |z|^n\)
  • \(|z|^2 = z\bar{z}\)
  • \(|z_1 + z_2|^2 = |z_1|^2 + |z_2|^2 + 2\text{Re}(z_1\bar{z}_2)\)
  • \(|z_1 - z_2|^2 = |z_1|^2 + |z_2|^2 - 2\text{Re}(z_1\bar{z}_2)\)
  • \(|z_1 + z_2|^2 + |z_1 - z_2|^2 = 2(|z_1|^2 + |z_2|^2)\) (Parallelogram Law)
  • \(|\text{Re}(z)| \leq |z|\), \(|\text{Im}(z)| \leq |z|\)

4.3 Distance Between Two Complex Numbers

Distance between points representing \(z_1\) and \(z_2\) in Argand plane:

\[d = |z_1 - z_2| = \sqrt{(a-c)^2 + (b-d)^2}\]

where \(z_1 = a + ib, z_2 = c + id\).

📝 PYQ — JEE Main 2024 (Apr 4 Shift 1)

Question: If \(|z - 2 - 3i| = 5\), then the maximum value of \(|z|\) is:

(a) \(5\)

(b) \(4 + \sqrt{13}\)

(c) \(3 + \sqrt{13}\)

(d) \(\sqrt{13} + 5\)

Solution:

\(|z - 2 - 3i| = 5\) represents a circle centered at \((2, 3)\) with radius \(5\).

Centre distance from origin \(= \sqrt{2^2 + 3^2} = \sqrt{13}\).

Maximum \(|z|\) = distance from origin to centre + radius \(= \sqrt{13} + 5\).

\[|z|_{\max} = 5 + \sqrt{13}\]

Answer: (d) \(\sqrt{13} + 5\)

Argument & Quadrant Rules

The argument (or amplitude) of a complex number is the angle made by the line joining the origin to the point with the positive real axis. It is one of the highest-yield topics in JEE.

5.1 Definition

🔥 Most Repeated PYQ — Argument Definition

For \(z = a + ib \neq 0\), the argument is:

\[\arg(z) = \theta = \tan^{-1}\left(\frac{b}{a}\right)\]

Principal value: \(\theta \in (-\pi, \pi]\). The argument is multi-valued: \(\arg(z) = \theta + 2k\pi\), but principal value is unique.

5.2 Quadrant-wise Argument

🔥 Most Repeated PYQ — Quadrant Argument

Let \(\alpha = \tan^{-1}|b/a|\). Then depending on the quadrant of \((a, b)\):

QuadrantSign of (a, b)arg(z)
Ia > 0, b > 0\(+\alpha\)
IIa < 0, b > 0\(\pi - \alpha\)
IIIa < 0, b < 0\(-(\pi - \alpha) = -\pi + \alpha\)
IVa > 0, b < 0\(-\alpha\)

Special cases:

  • Positive real axis: \(\arg = 0\)
  • Negative real axis: \(\arg = \pi\)
  • Positive imaginary axis: \(\arg = \pi/2\)
  • Negative imaginary axis: \(\arg = -\pi/2\)

5.3 Properties of Argument

🔥 Most Repeated PYQ — Argument Properties

  • \(\arg(z_1 z_2) = \arg(z_1) + \arg(z_2)\) (mod \(2\pi\))
  • \(\arg\left(\dfrac{z_1}{z_2}\right) = \arg(z_1) - \arg(z_2)\) (mod \(2\pi\))
  • \(\arg(z^n) = n \arg(z)\) (mod \(2\pi\))
  • \(\arg(\bar{z}) = -\arg(z)\)
  • \(\arg\left(\dfrac{1}{z}\right) = -\arg(z)\)
  • \(\arg(-z) = \arg(z) \pm \pi\)
  • \(\arg(z_1 \bar{z}_2) = \arg(z_1) - \arg(z_2)\)
  • If \(\arg(z_1) = \arg(z_2)\), then \(z_1, z_2, 0\) are collinear.

5.4 Relation: \(a = |z|\cos\theta, b = |z|\sin\theta\)

Given \(z = a + ib\) with modulus \(r\) and argument \(\theta\):

\[a = r\cos\theta, \quad b = r\sin\theta\]

So \(z = r(\cos\theta + i\sin\theta)\), the polar form.

📝 PYQ — JEE Main 2023 (Apr 8 Shift 2)

Question: The argument of \(\dfrac{1 + i}{1 - i}\) is:

(a) \(\pi/4\)

(b) \(\pi/2\)

(c) \(-\pi/2\)

(d) \(\pi\)

Solution:

\(\arg\left(\dfrac{1+i}{1-i}\right) = \arg(1+i) - \arg(1-i)\).

\(\arg(1+i) = \pi/4\) (Q1, \(a = b = 1\)).

\(\arg(1-i) = -\pi/4\) (Q4, \(a = 1, b = -1\)).

\[\arg = \frac{\pi}{4} - \left(-\frac{\pi}{4}\right) = \frac{\pi}{2}\]
\[\frac{\pi}{2}\]

Answer: (b) \(\pi/2\)

Polar & Euler (Exponential) Form

The polar form and Euler (exponential) form are the most elegant representations of complex numbers, especially useful for multiplication, division, and powers.

6.1 Polar Form

🔥 Most Repeated PYQ — Polar Form

For \(z = a + ib\) with \(r = |z|\) and \(\theta = \arg(z)\):

\[z = r(\cos\theta + i\sin\theta)\]

where \(r = \sqrt{a^2 + b^2}\) and \(\theta = \tan^{-1}(b/a)\) (quadrant-aware).

6.2 Euler's Formula & Euler Form

🔥 Most Repeated PYQ — Euler's Formula

Euler's formula:

\[e^{i\theta} = \cos\theta + i\sin\theta\]

So the Euler (exponential) form of \(z\) is:

\[z = re^{i\theta}\]

Beautiful identity (Euler's Identity): \(e^{i\pi} + 1 = 0\) — combines \(e, i, \pi, 1, 0\).

6.3 Multiplication/Division in Polar Form

If \(z_1 = r_1(\cos\theta_1 + i\sin\theta_1)\) and \(z_2 = r_2(\cos\theta_2 + i\sin\theta_2)\):

\[z_1 z_2 = r_1 r_2 \big[\cos(\theta_1 + \theta_2) + i\sin(\theta_1 + \theta_2)\big]\]
\[\frac{z_1}{z_2} = \frac{r_1}{r_2}\big[\cos(\theta_1 - \theta_2) + i\sin(\theta_1 - \theta_2)\big]\]

In Euler form: \(z_1 z_2 = r_1 r_2 e^{i(\theta_1 + \theta_2)}\), \(\dfrac{z_1}{z_2} = \dfrac{r_1}{r_2}e^{i(\theta_1 - \theta_2)}\).

Geometric meaning: Multiplying by \(re^{i\theta}\) scales by \(r\) and rotates by \(\theta\) (counter-clockwise).

📝 PYQ — JEE Main 2022 (July 27 Shift 1)

Question: The polar form of \(z = -1 + i\) is:

(a) \(\sqrt{2}\left(\cos\dfrac{\pi}{4} + i\sin\dfrac{\pi}{4}\right)\)

(b) \(\sqrt{2}\left(\cos\dfrac{3\pi}{4} + i\sin\dfrac{3\pi}{4}\right)\)

(c) \(2\left(\cos\dfrac{3\pi}{4} + i\sin\dfrac{3\pi}{4}\right)\)

(d) \(\sqrt{2}\left(\cos\dfrac{5\pi}{4} + i\sin\dfrac{5\pi}{4}\right)\)

Solution:

For \(z = -1 + i\): \(a = -1, b = 1\). Point lies in Q2.

\(r = |z| = \sqrt{1 + 1} = \sqrt{2}\).

\(\alpha = \tan^{-1}|1/(-1)| = \pi/4\). In Q2: \(\theta = \pi - \alpha = \pi - \pi/4 = 3\pi/4\).

\[z = \sqrt{2}\left(\cos\frac{3\pi}{4} + i\sin\frac{3\pi}{4}\right)\]

Answer: (b) \(\sqrt{2}\left(\cos\dfrac{3\pi}{4} + i\sin\dfrac{3\pi}{4}\right)\)

Argand Diagram & Geometric Representation

An Argand diagram is a plot of complex numbers as points in a plane with two perpendicular axes: the real axis (x-axis) and the imaginary axis (y-axis).

7.1 Plotting a Complex Number

A complex number \(z = a + ib\) is represented as the point \(P(a, b)\) in the Argand plane.

  • The x-coordinate gives the real part: \(\text{Re}(z) = a\)
  • The y-coordinate gives the imaginary part: \(\text{Im}(z) = b\)
  • Distance from origin \(= |z| = \sqrt{a^2 + b^2}\)
  • Angle with positive x-axis \(= \arg(z)\)

7.2 Vector Interpretation

A complex number \(z = a + ib\) can also be viewed as the vector \(\vec{OP}\) from origin \(O\) to point \(P(a, b)\).

Addition of complex numbers corresponds to vector addition (parallelogram law / head-to-tail rule).

7.3 Geometric Meaning of Operations

💡 Geometric Interpretation

  • Addition \(z_1 + z_2\): parallelogram law of vectors.
  • Subtraction \(z_1 - z_2\): vector from tip of \(z_2\) to tip of \(z_1\).
  • Multiplication by \(i\): rotates \(z\) by \(\pi/2\) counter-clockwise (no scaling since \(|i| = 1\)).
  • Multiplication by \(re^{i\theta}\): scales by \(r\) and rotates by \(\theta\).
  • Conjugate \(\bar{z}\): reflection in real axis.
  • Multiplication by \(-1\): rotation by \(\pi\) (point reflection in origin).

📝 PYQ — JEE Main 2021 (Jul 25 Shift 2)

Question: The locus of \(z\) satisfying \(|z - i| = |z + i|\) represents:

(a) A circle

(b) The real axis

(c) The imaginary axis

(d) A parabola

Solution:

\(z = x + iy\). Then \(|z - i|^2 = x^2 + (y-1)^2\) and \(|z + i|^2 = x^2 + (y+1)^2\).

Setting equal: \(x^2 + (y-1)^2 = x^2 + (y+1)^2 \Rightarrow (y-1)^2 = (y+1)^2 \Rightarrow -2y = 2y \Rightarrow y = 0\).

This is the real axis.

\[\text{Real axis}\]

Answer: (b) The real axis

Triangle Inequality

The triangle inequality is one of the most fundamental and frequently tested inequalities for complex numbers in JEE.

8.1 Statement

🔥 Most Repeated PYQ — Triangle Inequality

For any two complex numbers \(z_1, z_2\):

\[\big| |z_1| - |z_2| \big| \leq |z_1 + z_2| \leq |z_1| + |z_2|\]

Equivalently:

\[|z_1 + z_2| \leq |z_1| + |z_2| \quad \text{(upper bound)}\]
\[|z_1 - z_2| \geq \big| |z_1| - |z_2| \big| \quad \text{(lower bound)}\]

8.2 Equality Conditions

🔥 Most Repeated PYQ — Equality Conditions

  • Equality in \(|z_1 + z_2| \leq |z_1| + |z_2|\): when \(\arg(z_1) = \arg(z_2)\) (same argument, i.e., \(z_1, z_2\) are collinear with origin and in same direction), or one of them is zero.
  • Equality in \(|z_1 + z_2| \geq \big| |z_1| - |z_2| \big|\): when \(\arg(z_1) = \arg(z_2) + \pi\) (opposite directions, i.e., anti-parallel), or one of them is zero.
  • Equality in \(|z_1 - z_2| \geq \big| |z_1| - |z_2| \big|\): when \(z_1, z_2\) have same argument.

8.3 Generalized Triangle Inequality

For \(n\) complex numbers:

\[|z_1 + z_2 + \dots + z_n| \leq |z_1| + |z_2| + \dots + |z_n|\]

Equality when all \(z_k\) have the same argument.

📝 PYQ — JEE Main 2020 (Sep 4 Shift 1)

Question: The maximum value of \(|z_1 + z_2|\) when \(|z_1| = 3\) and \(|z_2| = 4\) is:

(a) \(5\)

(b) \(7\)

(c) \(12\)

(d) \(1\)

Solution:

By triangle inequality: \(|z_1 + z_2| \leq |z_1| + |z_2| = 3 + 4 = 7\).

Maximum \(= 7\), achieved when \(\arg(z_1) = \arg(z_2)\) (same direction).

\[|z_1 + z_2|_{\max} = 7\]

Answer: (b) \(7\)

Square Root of a Complex Number

Every non-zero complex number has exactly two square roots (which are negatives of each other). The square root is computed by setting up equations for real and imaginary parts.

9.1 Method

🔥 Most Repeated PYQ — Square Root Method

Let \(\sqrt{a + ib} = x + iy\) where \(x, y\) are real. Then \(a + ib = (x + iy)^2 = (x^2 - y^2) + i(2xy)\). So:

  • \(x^2 - y^2 = a\) ... (1)
  • \(2xy = b\) ... (2)

Also, \(|a + ib| = |(x + iy)^2| = (x^2 + y^2)\), so:

\[x^2 + y^2 = \sqrt{a^2 + b^2} \quad \dots (3)\]

From (1) and (3):

\[x^2 = \frac{\sqrt{a^2 + b^2} + a}{2}, \quad y^2 = \frac{\sqrt{a^2 + b^2} - a}{2}\]

Sign of \(xy\) = sign of \(b\) (from equation (2)).

9.2 Direct Formula

⭐ Important — Square Root Formula

Let \(r = |z| = \sqrt{a^2 + b^2}\). Then:

\[\sqrt{a + ib} = \pm\left[\sqrt{\frac{r + a}{2}} + i\,\text{sgn}(b)\sqrt{\frac{r - a}{2}}\right]\]

where \(\text{sgn}(b)\) is the sign of \(b\) (for \(b = 0\), the formula gives purely real or purely imaginary root).

9.3 Square Root using Polar Form

If \(z = r(\cos\theta + i\sin\theta)\), then:

\[\sqrt{z} = \pm\sqrt{r}\left(\cos\frac{\theta}{2} + i\sin\frac{\theta}{2}\right)\]

More generally, the two square roots are \(\pm\sqrt{r}\,e^{i\theta/2}\).

Cube Roots of Unity (ω)

The cube roots of unity are among the most important complex numbers in JEE. The symbol \(\omega\) (omega) is used for the principal non-real cube root.

10.1 Finding Cube Roots of 1

🔥 Most Repeated PYQ — Cube Roots of Unity

To find cube roots of 1, solve \(z^3 = 1\), i.e., \(z^3 - 1 = 0\):

\[z^3 - 1 = (z - 1)(z^2 + z + 1) = 0\]

So \(z = 1\) or \(z^2 + z + 1 = 0\). The non-real roots are:

\[\omega = \frac{-1 + i\sqrt{3}}{2} = e^{2\pi i/3}, \quad \omega^2 = \frac{-1 - i\sqrt{3}}{2} = e^{4\pi i/3}\]

The three cube roots of unity are: \(1, \omega, \omega^2\).

10.2 Properties of ω

🔥 Most Repeated PYQ — ω Properties

  • \(\omega^3 = 1\)
  • \(1 + \omega + \omega^2 = 0\) (most important identity)
  • \(\omega^2 = \bar{\omega}\) (conjugate of \(\omega\))
  • \(\omega \cdot \omega^2 = 1\), so \(\omega^2 = 1/\omega = \omega^{-1}\)
  • \(|\omega| = |\omega^2| = 1\)
  • \(\omega\) and \(\omega^2\) are roots of \(x^2 + x + 1 = 0\)
  • \(\omega^n = 1\) if \(n\) is a multiple of 3; \(\omega^n = \omega\) if \(n \equiv 1 \pmod 3\); \(\omega^n = \omega^2\) if \(n \equiv 2 \pmod 3\).
  • \(\omega^{3n} + \omega^{3n+1} + \omega^{3n+2} = 1 + \omega + \omega^2 = 0\)

10.3 Geometric Representation

💡 Equilateral Triangle

The three cube roots \(1, \omega, \omega^2\) form the vertices of an equilateral triangle inscribed in the unit circle centered at the origin.

  • \(1 = e^{0 \cdot i}\) at angle \(0\)
  • \(\omega = e^{2\pi i/3}\) at angle \(2\pi/3 = 120°\)
  • \(\omega^2 = e^{4\pi i/3}\) at angle \(4\pi/3 = 240°\)

Side length of triangle \(= |\omega - 1| = \sqrt{3}\). Centroid is at origin.

10.4 Cube Roots of Any Number

Cube roots of any complex number \(z = re^{i\theta}\) are:

\[z^{1/3} = r^{1/3} e^{i(\theta + 2k\pi)/3}, \quad k = 0, 1, 2\]

If \(a\) is one cube root of \(z\), the three cube roots are \(a, a\omega, a\omega^2\).

nth Roots of Unity

The nth roots of unity generalize the concept of cube roots. They form a regular \(n\)-gon inscribed in the unit circle.

11.1 Formula

🔥 Most Repeated PYQ — nth Roots of Unity

The \(n\) nth-roots of unity are:

\[1, \;\alpha, \;\alpha^2, \;\dots, \;\alpha^{n-1}\]

where \(\alpha = e^{2\pi i/n} = \cos\left(\dfrac{2\pi}{n}\right) + i\sin\left(\dfrac{2\pi}{n}\right)\).

Each root has the form:

\[\alpha_k = e^{2\pi i k/n}, \quad k = 0, 1, 2, \dots, n-1\]

11.2 Properties

🔥 Most Repeated PYQ — Properties

  • Each root has modulus \(1\): \(|\alpha_k| = 1\).
  • The roots form the vertices of a regular \(n\)-gon inscribed in the unit circle.
  • Sum of all \(n\) roots \(= 0\): \(1 + \alpha + \alpha^2 + \dots + \alpha^{n-1} = 0\).
  • Product of all \(n\) roots \(= (-1)^{n-1}\).
  • The roots satisfy \(z^n - 1 = 0\), i.e., they are roots of \(z^n - 1 = 0\).
  • \(z^n - 1 = (z - 1)(z^{n-1} + z^{n-2} + \dots + z + 1)\). So the non-trivial roots satisfy \(z^{n-1} + \dots + 1 = 0\).

11.3 nth Roots of Any Number

For \(z = re^{i\theta}\), the \(n\) nth-roots are:

\[z_k = r^{1/n} \, e^{i(\theta + 2k\pi)/n}, \quad k = 0, 1, \dots, n-1\]

If \(a\) is one nth-root of \(z\), the others are \(a\alpha, a\alpha^2, \dots, a\alpha^{n-1}\) where \(\alpha = e^{2\pi i/n}\).

De Moivre's Theorem

De Moivre's Theorem is a powerful result that connects complex numbers with trigonometry, allowing us to compute powers and roots of complex numbers easily.

12.1 Statement

🔥 Most Repeated PYQ — De Moivre's Theorem

For any integer \(n\) and any real \(\theta\):

\[(\cos\theta + i\sin\theta)^n = \cos(n\theta) + i\sin(n\theta)\]

In Euler form:

\[(e^{i\theta})^n = e^{in\theta}\]

Extension: For rational \(n = p/q\) (in lowest terms), the formula gives one of the \(q\) values of \((\cos\theta + i\sin\theta)^{p/q}\), specifically \(\cos\left(\dfrac{p\theta}{q}\right) + i\sin\left(\dfrac{p\theta}{q}\right)\).

12.2 Applications

💡 Key Applications

  • Finding powers of complex numbers: \((re^{i\theta})^n = r^n e^{in\theta}\).
  • Finding roots of complex numbers.
  • Deriving multiple-angle formulas: \(\cos n\theta, \sin n\theta\) in terms of \(\cos\theta, \sin\theta\).
  • Sum of trigonometric series.
  • Expanding \((\cos\theta + i\sin\theta)^n\) using binomial theorem and equating real & imaginary parts.

12.3 Expanding \((\cos\theta + i\sin\theta)^n\)

By binomial theorem:

\[(\cos\theta + i\sin\theta)^n = \sum_{k=0}^{n} \binom{n}{k} \cos^{n-k}\theta \cdot (i\sin\theta)^k\]

Equating real and imaginary parts with \(\cos(n\theta) + i\sin(n\theta)\) gives:

\[\cos(n\theta) = \cos^n\theta - \binom{n}{2}\cos^{n-2}\theta\sin^2\theta + \binom{n}{4}\cos^{n-4}\theta\sin^4\theta - \dots\]
\[\sin(n\theta) = \binom{n}{1}\cos^{n-1}\theta\sin\theta - \binom{n}{3}\cos^{n-3}\theta\sin^3\theta + \dots\]

12.4 Useful Trig Sum Identities (via De Moivre)

⭐ Important — Sum Identities

  • \(1 + \cos\theta + \cos 2\theta + \dots + \cos n\theta = \dfrac{\sin\left(\dfrac{(n+1)\theta}{2}\right) \cdot \cos\left(\dfrac{n\theta}{2}\right)}{\sin(\theta/2)}\)
  • \(\sin\theta + \sin 2\theta + \dots + \sin n\theta = \dfrac{\sin\left(\dfrac{n\theta}{2}\right) \cdot \sin\left(\dfrac{(n+1)\theta}{2}\right)}{\sin(\theta/2)}\)
  • Sum of roots of unity: \(\sum_{k=0}^{n-1} e^{2\pi i k/n} = 0\).

Rotation Theorem

The Rotation Theorem (also called the concept of rotation) is fundamental for solving geometry problems with complex numbers, especially those involving angles in triangles.

14.1 Statement

🔥 Most Repeated PYQ — Rotation Theorem

If \(z_1, z_2, z_3\) are three complex numbers and the angle at \(z_1\) from vector \(\vec{z_1 z_2}\) to vector \(\vec{z_1 z_3}\) is \(\theta\) (counter-clockwise), then:

\[\frac{z_3 - z_1}{z_2 - z_1} = \frac{|z_3 - z_1|}{|z_2 - z_1|} \cdot e^{i\theta}\]

Equivalently, to rotate a vector \(z - z_0\) by angle \(\theta\) about point \(z_0\), multiply by \(e^{i\theta}\):

\[z_{\text{rotated}} = z_0 + (z - z_0)e^{i\theta}\]

14.2 Equilateral Triangle Condition

🔥 Most Repeated PYQ — Equilateral Triangle

Three points \(z_1, z_2, z_3\) form an equilateral triangle (in some order) iff:

\[z_1 + \omega z_2 + \omega^2 z_3 = 0 \quad \text{OR} \quad z_1 + \omega^2 z_2 + \omega z_3 = 0\]

Equivalently: \(z_1^2 + z_2^2 + z_3^2 = z_1 z_2 + z_2 z_3 + z_3 z_1\).

14.3 Square Condition

Four points \(z_1, z_2, z_3, z_4\) form a square (in order) iff:

\[z_2 - z_1 = i(z_3 - z_2) = -(z_4 - z_3) = -i(z_1 - z_4)\]

Or more simply: opposite sides equal and adjacent sides perpendicular.

14.4 Centroid, Orthocentre, Circumcentre

💡 Triangle Centers in Complex Plane

  • Centroid: \(G = \dfrac{z_1 + z_2 + z_3}{3}\)
  • Orthocentre (if circumcentre is at origin): \(H = z_1 + z_2 + z_3\)
  • Euler line: \(O, G, H\) are collinear with \(OG : GH = 1 : 2\).
  • If vertices are on unit circle: \(H = z_1 + z_2 + z_3\).

📝 PYQ — JEE Main 2024 (Apr 5 Shift 1)

(b) \(z_1 + z_2 + z_3 = 0\)

(c) \(z_1 z_2 z_3 = 1\)

(d) None

Solution:

For an equilateral triangle with vertices \(z_1, z_2, z_3\), the standard identity is:

\[z_1^2 + z_2^2 + z_3^2 = z_1 z_2 + z_2 z_3 + z_3 z_1\]

This comes from the rotation condition: rotating \(z_2 - z_1\) by \(\pi/3\) gives \(z_3 - z_1\), so \(z_3 - z_1 = (z_2 - z_1)e^{i\pi/3}\). Expanding and using \(|z_2 - z_1| = |z_3 - z_1|\) leads to the identity.

Geometry in Complex Plane

Many coordinate geometry formulas (distance, section, centroid, area) can be expressed elegantly using complex numbers.

15.1 Distance Formula

🔥 Most Repeated PYQ — Distance

Distance between points \(z_1\) and \(z_2\):

\[d = |z_1 - z_2|\]

15.2 Section Formula

🔥 Most Repeated PYQ — Section Formula

Point dividing \(z_1 z_2\) in ratio \(m : n\):

  • Internal: \(z = \dfrac{mz_2 + nz_1}{m + n}\)
  • External: \(z = \dfrac{mz_2 - nz_1}{m - n}\) (\(m \neq n\))

Midpoint (\(m = n = 1\)): \(z = \dfrac{z_1 + z_2}{2}\).

15.3 Centroid

Centroid of triangle with vertices \(z_1, z_2, z_3\):

\[G = \frac{z_1 + z_2 + z_3}{3}\]

15.4 Area of Triangle

⭐ Important — Area Formula

Area of triangle with vertices \(z_1, z_2, z_3\):

\[A = \frac{1}{4i}\begin{vmatrix} z_1 & \bar{z}_1 & 1 \\ z_2 & \bar{z}_2 & 1 \\ z_3 & \bar{z}_3 & 1 \end{vmatrix}\]

Or in expanded form, with \(z_k = x_k + iy_k\):

\[A = \frac{1}{2}|x_1(y_2 - y_3) + x_2(y_3 - y_1) + x_3(y_1 - y_2)|\]

15.5 Collinearity

Three points \(z_1, z_2, z_3\) are collinear iff:

\[\begin{vmatrix} z_1 & \bar{z}_1 & 1 \\ z_2 & \bar{z}_2 & 1 \\ z_3 & \bar{z}_3 & 1 \end{vmatrix} = 0\]

Equivalently, \(\dfrac{z_3 - z_1}{z_2 - z_1}\) is purely real (i.e., has zero imaginary part).

Straight Line in Complex Plane

A straight line in the complex plane can be expressed in several equivalent forms using complex numbers.

16.1 Equation of a Line

🔥 Most Repeated PYQ — Line Equation

Line through points \(z_1\) and \(z_2\):

\[\begin{vmatrix} z & \bar{z} & 1 \\ z_1 & \bar{z}_1 & 1 \\ z_2 & \bar{z}_2 & 1 \end{vmatrix} = 0\]

Or in parametric form:

\[z = z_1 + t(z_2 - z_1), \quad t \in \mathbb{R}\]

General form: \(\bar{a}z + a\bar{z} + b = 0\), where \(a \in \mathbb{C}\), \(b \in \mathbb{R}\).

16.2 Slope-Intercept Form

A line with slope \(m = \tan\theta\) and passing through point \(z_0\):

\[z - z_0 = t \cdot e^{i\theta}, \quad t \in \mathbb{R}\]

Or: \(\text{Im}\left(\dfrac{z - z_0}{e^{i\theta}}\right) = 0\), i.e., \(\dfrac{z - z_0}{e^{i\theta}}\) is real.

16.3 Perpendicular Distance

⭐ Important — Perpendicular Distance

Perpendicular distance from point \(z_0\) to line through \(z_1, z_2\):

\[d = \left|\text{Im}\left((z_0 - z_1)\overline{(z_2 - z_1)}\right)\right| / |z_2 - z_1|\]

16.4 Half-Planes

💡 Half-Plane Conditions

For line through \(z_1, z_2\):

  • Point \(z\) is on line iff \(\dfrac{z - z_1}{z_2 - z_1}\) is real.
  • Point \(z\) is on left of \(\vec{z_1 z_2}\) iff \(\text{Im}\left(\dfrac{z - z_1}{z_2 - z_1}\right) > 0\).
  • Point \(z\) is on right iff \(\text{Im}\left(\dfrac{z - z_1}{z_2 - z_1}\right) < 0\).

Circle in Complex Plane

A circle in the complex plane is the locus of points equidistant from a fixed point (centre). Circles appear very frequently in locus problems.

17.1 Equation of Circle

🔥 Most Repeated PYQ — Circle Equation

Circle with centre \(z_0\) and radius \(r\):

\[|z - z_0| = r\]

Squaring: \(|z - z_0|^2 = r^2\), i.e., \((z - z_0)(\bar{z} - \bar{z}_0) = r^2\).

\[z\bar{z} - \bar{z}_0 z - z_0 \bar{z} + |z_0|^2 - r^2 = 0\]

17.2 General Equation

General equation of circle:

\[z\bar{z} + \bar{a}z + a\bar{z} + b = 0\]

where \(a \in \mathbb{C}\), \(b \in \mathbb{R}\). Centre: \(-a\). Radius: \(\sqrt{|a|^2 - b}\).

For real circle, need \(|a|^2 > b\).

17.3 Interior and Exterior

💡 Inside/Outside

For circle \(|z - z_0| = r\):

  • Interior: \(|z - z_0| < r\)
  • Exterior: \(|z - z_0| > r\)
  • On circle: \(|z - z_0| = r\)

17.4 Diameter Form

Circle with diameter endpoints \(z_1\) and \(z_2\):

\[(z - z_1)(\bar{z} - \bar{z}_2) + (z - z_2)(\bar{z} - \bar{z}_1) = 0\]

Or: \(\arg\left(\dfrac{z - z_1}{z - z_2}\right) = \pm \dfrac{\pi}{2}\), i.e., \(\dfrac{z - z_1}{z - z_2}\) is purely imaginary.

📝 PYQ — JEE Main 2018 (Apr 8 Shift 1)

Question: The locus of \(z\) satisfying \(|z - 3i| = |z + 3i|\) is:

(a) A circle of radius 3

(b) The real axis

(c) The imaginary axis

(d) An ellipse

Solution:

Let \(z = x + iy\). Then \(|z - 3i|^2 = x^2 + (y - 3)^2\) and \(|z + 3i|^2 = x^2 + (y + 3)^2\).

Setting equal: \(x^2 + (y-3)^2 = x^2 + (y+3)^2 \Rightarrow (y-3)^2 = (y+3)^2 \Rightarrow y^2 - 6y + 9 = y^2 + 6y + 9 \Rightarrow -12y = 0 \Rightarrow y = 0\).

This is the real axis.

\[\text{Real axis}\]

Frequently Asked Questions

What is iota (i) in complex numbers?

Iota, denoted by i, is the imaginary unit defined by i = √(-1). It satisfies i² = -1. Integral powers of i follow a cyclic pattern: i¹ = i, i² = -1, i³ = -i, i⁴ = 1, and then the cycle repeats. In general, i⁴ⁿ = 1, i⁴ⁿ⁺¹ = i, i⁴ⁿ⁺² = -1, i⁴ⁿ⁺³ = -i.

What is the modulus of a complex number?

For z = a + ib, the modulus is |z| = √(a² + b²). It represents the distance of the point (a, b) from the origin in the Argand plane. Properties include |z₁z₂| = |z₁||z₂|, |z₁/z₂| = |z₁|/|z₂|, |z|² = z·z̄, and |z₁ + z₂| ≤ |z₁| + |z₂| (triangle inequality).

What is the argument of a complex number?

The argument (amplitude) of z = a + ib is the angle made by the line joining origin to (a, b) with the positive x-axis: arg(z) = tan⁻¹(b/a). The principal value lies in (-π, π]. The argument depends on the quadrant: Q1 → θ, Q2 → π - tan⁻¹|b/a|, Q3 → -π + tan⁻¹|b/a|, Q4 → -tan⁻¹|b/a|.

What is Euler's form of a complex number?

Euler's form (exponential form) of a complex number is z = re^(iθ), where r = |z| is the modulus and θ = arg(z) is the argument. This follows from Euler's formula: e^(iθ) = cos θ + i sin θ. So z = r(cos θ + i sin θ) = re^(iθ). It is the most compact form for multiplication and powers.

What is De Moivre's theorem?

De Moivre's theorem states that (cos θ + i sin θ)ⁿ = cos(nθ) + i sin(nθ) for any integer n. In Euler form: (e^(iθ))ⁿ = e^(inθ). It is used to find powers of complex numbers, nth roots, and to derive multiple-angle formulas for cos and sin.

What are cube roots of unity?

The cube roots of unity are 1, ω, ω², where ω = e^(2πi/3) = -1/2 + i√3/2 and ω² = e^(4πi/3) = -1/2 - i√3/2. Key properties: ω³ = 1, 1 + ω + ω² = 0, ω² = ω̄ (conjugate), |ω| = 1, ω and ω² are roots of x² + x + 1 = 0.

What is the triangle inequality for complex numbers?

Triangle inequality: |z₁ + z₂| ≤ |z₁| + |z₂|. Equality holds when z₁ and z₂ have the same argument (i.e., they are collinear with origin and in the same direction), or one of them is zero. Also, ||z₁| - |z₂|| ≤ |z₁ - z₂|, with equality when z₁ and z₂ have the same argument.

What is the rotation theorem in complex numbers?

Rotation theorem: If z₁, z₂, z₃ are vertices of a triangle and the angle at z₁ (from z₁z₂ to z₁z₃) is θ, then (z₃ - z₁)/(z₂ - z₁) = (|z₃ - z₁|/|z₂ - z₁|) · e^(iθ). In particular, if z₁, z₂, z₃ form an equilateral triangle, then z₁ + ωz₂ + ω²z₃ = 0 (or with ω, ω² interchanged).

How many questions come from Complex Numbers in JEE Mains?

On average 1-2 questions (4-8 marks) appear from Complex Numbers in every JEE Main session. Most repeated topics are: modulus and argument, cube roots of unity (ω properties), De Moivre's theorem, triangle inequality, conjugate properties, polar/Euler form conversion, and (1 + ω)ⁿ type problems.

How to find square root of a complex number a + ib?

Let √(a + ib) = x + iy. Squaring: x² - y² = a, 2xy = b. Also x² + y² = √(a² + b²). Solving: x² = (a + √(a² + b²))/2, y² = (-a + √(a² + b²))/2, with sign of xy = sign of b. Formula: √(a + ib) = ±[(√((|z| + a)/2) + i·sgn(b)·√((|z| - a)/2))], where |z| = √(a² + b²).

Complex Numbers — Complete JEE Study Guide

Complex Numbers is one of the highest-scoring and most conceptual chapters in JEE Algebra. It typically contributes 1-2 questions in every JEE Main session, and 1-3 in JEE Advanced. The chapter combines algebraic manipulation with geometric intuition via the Argand plane.

The most important topics for JEE from this chapter are modulus (\(|z| = \sqrt{a^2 + b^2}\)), argument (\(\arg(z) = \tan^{-1}(b/a)\) with quadrant awareness), conjugate properties (\(z\bar{z} = |z|^2\), \(\overline{z_1 z_2} = \bar{z}_1\bar{z}_2\)), polar form (\(z = r(\cos\theta + i\sin\theta)\)), Euler form (\(z = re^{i\theta}\)), triangle inequality (\(|z_1+z_2| \leq |z_1|+|z_2|\)), square root of complex number, cube roots of unity (\(\omega = e^{2\pi i/3}\), \(1+\omega+\omega^2=0\)), nth roots of unity, De Moivre's theorem (\((\cos\theta+i\sin\theta)^n = \cos n\theta + i\sin n\theta\)), rotation theorem, and locus problems.

For modulus-argument problems, remember key properties: \(|z_1 z_2| = |z_1||z_2|\), \(|z_1/z_2| = |z_1|/|z_2|\), \(\arg(z_1 z_2) = \arg z_1 + \arg z_2\), \(\arg(z_1/z_2) = \arg z_1 - \arg z_2\), \(\arg(\bar{z}) = -\arg z\). The quadrant-wise argument formula is critical: in Q1 use \(\tan^{-1}(b/a)\), in Q2 use \(\pi - \tan^{-1}|b/a|\), in Q3 use \(-\pi + \tan^{-1}|b/a|\), in Q4 use \(-\tan^{-1}|b/a|\).

For ω problems, master the cyclic nature: \(\omega^3 = 1\), so reduce exponents mod 3. Use \(1 + \omega + \omega^2 = 0\) to simplify sums. Useful identities: \(1 + \omega = -\omega^2\), \(1 + \omega^2 = -\omega\), \(\omega + \omega^2 = -1\), \((1-\omega)(1-\omega^2) = 3\). For \((1 + \omega)^n + (1 + \omega^2)^n = (-1)^n(\omega^n + \omega^{2n})\), which equals \(2(-1)^n\) if \(n \equiv 0 \pmod 3\) and \((-1)^{n+1}\) otherwise.

De Moivre's theorem \((\cos\theta + i\sin\theta)^n = \cos n\theta + i\sin n\theta\) is used to compute powers of complex numbers in polar/Euler form. Combined with the binomial theorem, it gives multiple-angle formulas: \(\cos 3\theta = 4\cos^3\theta - 3\cos\theta\), \(\sin 3\theta = 3\sin\theta - 4\sin^3\theta\).

The triangle inequality \(\big||z_1| - |z_2|\big| \leq |z_1 + z_2| \leq |z_1| + |z_2|\) is fundamental. Equality in the upper bound holds when \(z_1, z_2\) have the same argument (parallel, same direction); equality in the lower bound holds when they have opposite arguments (anti-parallel). The parallelogram law \(|z_1 + z_2|^2 + |z_1 - z_2|^2 = 2(|z_1|^2 + |z_2|^2)\) is also frequently tested.

For geometry problems, the rotation theorem is key: if \(z_1, z_2, z_3\) form a triangle with angle \(\theta\) at \(z_1\), then \((z_3 - z_1)/(z_2 - z_1) = (|z_3 - z_1|/|z_2 - z_1|)e^{i\theta}\). Equilateral triangles satisfy \(z_1 + \omega z_2 + \omega^2 z_3 = 0\) (or with \(\omega, \omega^2\) swapped), or equivalently \(z_1^2 + z_2^2 + z_3^2 = z_1 z_2 + z_2 z_3 + z_3 z_1\).

The section formula \(z = (mz_2 + nz_1)/(m+n)\) (internal) and centroid \(G = (z_1 + z_2 + z_3)/3\) are direct analogues of coordinate geometry. The circle \(|z - z_0| = r\) has centre \(z_0\) and radius \(r\); in general form: \(z\bar{z} + \bar{a}z + a\bar{z} + b = 0\) with centre \(-a\) and radius \(\sqrt{|a|^2 - b}\).

Common locus patterns: \(|z - z_1| = |z - z_2|\) gives perpendicular bisector of segment \(z_1 z_2\); \(|z - z_1| + |z - z_2| = k\) (\(k > |z_1 - z_2|\)) gives ellipse; \(\big||z - z_1| - |z - z_2|\big| = k\) gives hyperbola; \(\arg(z - z_0) = \theta\) gives a ray; \(\arg((z - z_1)/(z - z_2)) = \theta\) gives an arc of a circle through \(z_1, z_2\).

For square root of \(a + ib\): use \(\sqrt{a + ib} = \pm\left[\sqrt{(r+a)/2} + i\,\text{sgn}(b)\sqrt{(r-a)/2}\right]\), where \(r = \sqrt{a^2 + b^2}\). Practice with examples like \(\sqrt{3 + 4i} = \pm(2 + i)\), \(\sqrt{-7 - 24i} = \pm(3 - 4i)\), \(\sqrt{-8 + 6i} = \pm(1 + 3i)\).

Finally, Euler's identity \(e^{i\pi} + 1 = 0\) beautifully connects the five most important constants in mathematics: \(e, i, \pi, 1, 0\). The Euler form \(z = re^{i\theta}\) is the most compact representation and makes multiplication, division, and powers trivial: \(z_1 z_2 = r_1 r_2 e^{i(\theta_1 + \theta_2)}\), \(z_1/z_2 = (r_1/r_2) e^{i(\theta_1 - \theta_2)}\), \(z^n = r^n e^{in\theta}\).
