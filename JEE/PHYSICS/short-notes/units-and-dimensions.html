1. Physical Quantities

A physical quantity = anything that can be measured, expressed as Numerical value × Unit. It stays constant regardless of the unit chosen: $n_1u_1 = n_2u_2$ (larger unit → smaller numerical value).

Fundamental (Base) Quantities

Independent, cannot be derived: Mass, Length, Time, Current, Temperature, Amount of substance, Luminous Intensity + 2 supplementary (plane angle, solid angle).

Derived Quantities

Expressed via fundamentals: Area, Volume, Velocity, Force, Energy, Pressure, etc. — 99% of physics quantities.

Scalars

Magnitude only, obey ordinary algebra: mass, time, speed, energy, temperature, distance, work, potential.

Vectors

Magnitude + direction, obey vector algebra: displacement, velocity, acceleration, force, momentum, torque, E, B.

💡 Trick: "My Large Tiger Can Eat Little Ants" → Mass, Length, Time, Current, Temperature, Luminous Intensity, Amount of substance.

2. Systems of Units

A system of units is a set where certain units are chosen fundamental and all others derived. Four historical systems matter for JEE:

SystemLengthMassTime
CGScentimetregramsecond
MKSmetrekilogramsecond
FPSfootpoundsecond
SImetrekilogramsecond (+4 more base units)

In contrast to the cgs and the fps systems of units, the mks system is a coherent system of units in mechanics — coherent means all derived units are obtained by multiplying/dividing fundamental units with no numerical factors. The units of mass, length and time in mks/cgs/fps can be used to obtain units of physical quantities in mechanics only (not electricity/heat) — that's why SI (7 base units) was adopted universally.

⚠️ SI is the only system with base units for ALL branches of physics (mechanics + heat + electricity + light + chemistry).

5. Dimensional Constants vs Dimensionless Constants

Dimensional Constants

Have dimensions, fixed value: G, h, c (speed of light), R, k (Boltzmann), ε₀, μ₀, σ (Stefan's)

Dimensionless Constants

No dimensions: π, e, ½, 2, all pure numbers, refractive index, Reynolds number

6. Dimensional Analysis

Principle of Homogeneity: In a correct equation, every additive term must have the same dimensions; only like quantities add/subtract.

3 Applications:

  1. Checking correctness of an equation (necessary but not sufficient condition)
  2. Deriving a formula when the quantity depends on a product of powers of others (no sum of terms)
  3. Converting units between systems
Method: Assume $Q = kA^aB^bC^c$ → substitute dimensions of A, B, C → equate powers of M, L, T on both sides → solve simultaneous equations for a, b, c.
Example: pendulum period $T=k\sqrt{L/g}$ — dimensional analysis gives the form, but constant $k=2\pi$ needs calculus/experiment.
❌ Limitations:
  • Cannot find dimensionless constants (2π, ½, e)
  • Fails when RHS has 2+ terms of same dimension added/subtracted (e.g., $s=ut+\frac12at^2$)
  • Cannot handle trigonometric, exponential, logarithmic functions (their arguments must be dimensionless, but the analysis can't derive the function itself)
  • Cannot distinguish scalar vs vector nature
  • Cannot decide between quantities having identical dimensions (e.g., torque vs energy)
  • Dimensionally correct ≠ physically correct

7. Significant Figures

  • All non-zero digits → significant (1234 → 4 S.F.)
  • Zeros between non-zero digits → significant (1002 → 4 S.F.)
  • Leading zeros → NOT significant (0.0025 → 2 S.F.)
  • Trailing zeros after decimal → significant (2.500 → 4 S.F.)
  • Trailing zeros in integer w/o decimal → ambiguous (2500 → 2,3, or 4 S.F.; use scientific notation to clarify)
  • Exact/counting numbers, and constants like π (in a formula) → infinite S.F.
  • Changing units does NOT change number of S.F.
Addition/Subtraction: keep least number of decimal places among terms.
Multiplication/Division: keep least number of significant figures among factors.
Rounding off: digit <5 → drop • >5 → round up preceding digit • exactly 5 → round to nearest even digit (e.g., 3.145→3.14, 3.155→3.16).

8. Error Analysis

Systematic

One-directional: instrumental, zero error, calibration, personal — correctable

Random

Unpredictable fluctuations — reduced by averaging repeated readings

Gross

Human mistake, wrong reading/recording — avoided by care

Absolute error: $\Delta a_i=|a_{mean}-a_i|$  |  Mean absolute error: $\overline{\Delta a}=\dfrac{\Sigma|\Delta a_i|}{n}$
Relative error: $\dfrac{\overline{\Delta a}}{a_{mean}}$  |  % error: $\dfrac{\overline{\Delta a}}{a_{mean}}\times100\%$
OperationError Propagation
Z = A ± BΔZ = ΔA + ΔB
Z = A × B or A/BΔZ/Z = ΔA/A + ΔB/B
Z = AⁿΔZ/Z = n(ΔA/A)
Z = AᵖBᑫ/CʳΔZ/Z = pΔA/A + qΔB/B + rΔC/C
⚠️ Errors always ADD in multiplication/division/power (worst-case, never subtract) • never round mid-calculation • max % error decides significant figures of final result.

9. Instruments & Least Count

Vernier Caliper: $LC = 1\,MSD - 1\,VSD$ (typically 0.01 cm). Zero error (+) if VSD zero lies right of MSD zero when jaws closed; (−) if left. Corrected reading = Observed reading − Zero error.
Screw Gauge (Micrometer): $LC = \dfrac{Pitch}{No.\ of\ circular\ scale\ divisions}$. Reading = MSR + (CSR × LC) − zero error. Backlash error avoided by rotating screw in one direction only.

10. Unit Conversion Formula

$$n_2 = n_1\left[\frac{M_1}{M_2}\right]^a\left[\frac{L_1}{L_2}\right]^b\left[\frac{T_1}{T_2}\right]^c$$ a, b, c = powers of M, L, T for that quantity's dimensional formula; subscript 1 = old system, 2 = new system.

Example: Convert 1 Newton (SI) to CGS (dyne). Force = [MLT⁻²] → a=1,b=1,c=−2. $$n_2 = 1\times\left[\frac{1000\,g}{1\,g}\right]^1\left[\frac{100\,cm}{1\,cm}\right]^1\left[\frac{1\,s}{1\,s}\right]^{-2}=10^5$$ So 1 N = 10⁵ dyne.

⚡ Final 2-Minute Cheat Sheet

  • 7 base quantities + 2 supplementary (rad, sr — dimensionless)
  • kg = only base unit with a prefix
  • Homogeneity: only same-dimension terms add/subtract
  • Dimensional analysis: derive form, NOT numerical constants
  • S.F.: leading zeros never count; trailing zeros after decimal always count
  • Addition/Subtraction → match decimal places; Multiplication/Division → match S.F.
  • Errors always add (never subtract) in product/quotient/power rules
  • Energy family (KE, PE, Work, Torque, Heat) = [ML²T⁻²] always
  • Unit conversion: $n_2=n_1[M_1/M_2]^a[L_1/L_2]^b[T_1/T_2]^c$
