# ------------------------------------------------------------
# SCOPE
# ------------------------------------------------------------

# In scope for responsible disclosure:
#   - XSS, CSRF, or injection vulnerabilities on any page
#   - Authentication or data exposure issues (if any arise)
#   - Malicious ad injection or third-party script compromise
#   - Subdomain takeover or DNS misconfiguration
#   - Any vulnerability that could harm site visitors or their data

# Out of scope:
#   - Rate limiting on public, unauthenticated pages
#   - Self-XSS requiring user to paste code into browser console
#   - Missing security headers that have no practical exploit path
#   - Clickjacking on pages with no sensitive actions
#   - Social engineering or phishing unrelated to our infrastructure
